# Recruitment System

A web-based recruitment system and talent network centered in Enugu and South East Nigeria.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Deploy to GitHub Pages

Push to the `main` branch. The GitHub Actions workflow builds and deploys the site automatically.

Published site: https://metta-tony.github.io/recruitment-system/
